## 五、明天的完整流程

### 第 1 步：确认训练完成

```powershell
ssh -i C:\Users\Reinon\ta-team3\team_key -p 20100 root@120.92.21.123 `
  "cat /outputs/webui/runs/v3-raised-bedeab/status.json; echo; ls /outputs/checkpoints/pi05_teleavatar_v2/v3-raised/"
```

期望 `state: done`，且有 `2000 4000 6000` 目录。

### 第 2 步：传 checkpoint 到 B70（约 12 GB）

**B70 直连 A100 是通的**（已验证）：

```bash
# 在 B70 上
ssh -i /root/ta_key -p 20100 -o StrictHostKeyChecking=accept-new root@120.92.21.123 "echo OK"

rm -rf /root/jax_ckpt && mkdir -p /root/jax_ckpt

ssh -i /root/ta_key -p 20100 root@120.92.21.123 \
  "cd /outputs/checkpoints/pi05_teleavatar_v2/v3-raised/6000 && tar cf - params assets" \
  | tar xf - -C /root/jax_ckpt

du -sh /root/jax_ckpt/params
```

**实测速度约 72 MB/s，12 GB 约 3 分钟。**

### 第 3 步：转 PyTorch（约 15 分钟）

```bash
rm -rf /root/ckpt_out

OPENPI_DIR=/root/USB/deploy/server/openpi XPU=0 GPUS=none OUTPUT_DIR=/root/ckpt_out \
  DOCKER_RUN_EXTRA="-e JAX_PLATFORMS=cpu -v /root/jax_ckpt:/jax:ro" \
  /root/USB/deploy/server/openpi-xpu-env/scripts/run.sh \
  python examples/convert_jax_model_to_pytorch.py \
    --checkpoint-dir /jax \
    --config-name pi05_teleavatar_v2 \
    --output-path /outputs/pi05_teleavatar_v2_pytorch \
    --precision bfloat16
```

成功标志：

```
Loaded 811 tensors; missing keys: []; unexpected keys: []
Model conversion completed successfully!
```

产物：`/root/ckpt_out/pi05_teleavatar_v2_pytorch/model.safetensors`（约 6.8 GB）

### 第 4 步：建软链（必做，容易漏）

```bash
cd /root/ckpt_out/pi05_teleavatar_v2_pytorch/assets
ls                          # 应该看到 move_raised
ln -sfn move_raised path-to-dataset    # ⚠️ 名字必须是 path-to-dataset
ls -la
```

**16 维配置要求软链名是 `path-to-dataset`**（chassis 配置才是 `checkout_224_plus_no_scan_224`）。

### 第 5 步：起 server

```bash
cd /root/USB/deploy/server/openpi-xpu-env

OPENPI_DIR=/root/USB/deploy/server/openpi \
DOCKER_RUN_EXTRA="-p 8000:8000 -v /root/ckpt_out/pi05_teleavatar_v2_pytorch:/ckpt:ro" \
  ./scripts/run.sh python scripts/serve_policy.py --env TELEAVATAR --warmup \
  policy:checkpoint --policy.config pi05_teleavatar_v2 --policy.dir /ckpt \
  --policy.pytorch-device xpu --policy.pytorch-compile-mode default 2>&1 | tee ~/server.log
```

期望：`server listening on 0.0.0.0:8000`，GPU 0 显存约 7.8 GB。

## 六、必记的坑（都是踩过的）

| # | 坑 | 表现 | 处理 |
|---|---|---|---|
| 1 | **急停没旋出** | 手臂完全不动，但软件层一切正常 | 推一下手臂，掰不动=有力 |
| 2 | **FSM 心跳没发** | 命令到 CAN 但电机不执行 | 心跳必须和程序**同一 shell** |
| 3 | **用 chassis 配置训练** | loss 炸到百万（v1 的失败） | 必须用 `pi05_teleavatar_v2`（16 维） |
| 4 | **保存间隔 250** | 31 个 checkpoint = 1.3 TB 爆盘 | 改成 2000 |
| 5 | **用 zero.py 摆位** | 起点和训练数据不符，模型乱动 | 用 `pose_raised.sh` |
| 6 | **软链名错** | server 启动报找不到归一化统计 | 16 维用 `path-to-dataset` |
| 7 | **client 容器跑久** | participant 耗尽、订阅丢失、收不到状态 | 每轮测试前重启容器 |
| 8 | **`| tail -N`** | 转换看起来卡住（输出被缓冲） | 用 `| tee` |
| 9 | **exFAT 盘放 SSH 私钥** | 登录失败，权限过宽 | 放 NTFS |
| 10 | **j7 贴限位** | 命令被夹在 0.7，手臂不动 | 下批录制把 j7 收到 0.3–0.4 |
