## 三、结论

1. **模型完全正常**：14 个关节全程平均误差 **0.006~0.011 弧度（0.3°~0.6°）**
2. **误差不累积**：每个 chunk 末端偏差仍 0.008~0.010 弧度
3. **左右臂都正常**，不存在"右臂特别差"的情况
4. 所以实机上"右臂往后走、全顶限位"**100% 是推理端配置问题**，不是模型问题

## 四、已经定位的推理端问题

```
A100 训练:  use_delta_joint_actions = False   （绝对关节角）
B70  推理:  use_delta_joint_actions = True    （增量关节角，代码版本较新）
→ 推理时把当前关节角加了两次 → 下发值 ≈ 当前值 × 2 → 全顶限位
```

修复：见 [`../脚本/fix_b70_absolute.py`](../脚本/fix_b70_absolute.py)

## 五、这个仿真器的其他用途

- 换 checkpoint 先离线比一轮，不用占机器人
- 改 prompt / 改图像处理 / 改归一化，先离线验证
- 怀疑数据质量时，离线跑几帧就能看出模型学到没学到
- 训练完立刻验证，不必等到部署
