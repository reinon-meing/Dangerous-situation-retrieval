# 抓取后"停住不动"的三种办法（2026-11-15）

> 场景：模型抓住沙包、抬起来之后，希望它**停下来保持不动**，不要继续推理乱动。

---

## 办法 A：直接停推理（最快，但夹持力不确定）

```bash
docker exec openpi-xpu-client pkill -INT -f "teleavatar_v2/main.py"
docker exec openpi-xpu-client bash -c "ps aux | grep main.py | grep -v grep"
```

**原理**：`main.py` 停了之后不再发 `/api/fsm/enable` 心跳，官方文档写明
**"超过 1 秒未收到 1.0 会自动暂停"** → 手臂保持当前姿态。

⚠️ 但**夹爪的保持力没有保证** —— 停发后夹爪控制器行为由固件决定，可能会松。

---

## 办法 B：保持脚本（推荐，稳定）

停掉推理后，跑 [`hold_now.py`](hold_now.py)：它持续把**当前姿态 + 夹爪触发值**发回去，
手臂被钉住，夹爪保持夹紧力。

```bash
# 夹紧保持
docker exec -i openpi-xpu-client /usr/local/bin/openpi-client-entrypoint.sh python /app/hold_now.py
```

```bash
# 保持姿态但松开夹爪（交付时用）
docker exec -i openpi-xpu-client /usr/local/bin/openpi-client-entrypoint.sh bash -c 'GRIP_TRIGGER=0.0 python /app/hold_now.py'
```

**运行时会打印**：

```
保持姿态:
  左: [0.58, 1.51, -1.04, 0.43, 0.52, -0.02, 0.10]
  右: [...]
夹爪 trigger = 1.00 （1.0=夹紧, 0.0=松开）
按 Ctrl-C 结束
```

- `Ctrl-C` 结束（心跳断，1 秒后机器人自动暂停）
- 参数：`GRIP_TRIGGER`（0~1，1=夹紧）、`HOLD_HZ`（默认 50）

---

## 办法 C：定时停止 + 自动保持（一条命令搞定）

把"跑模型 → N 秒后停 → 立刻保持"写在一起：

```bash
docker exec -i openpi-xpu-client /usr/local/bin/openpi-client-entrypoint.sh bash -c '
python examples/teleavatar_v2/main.py --remote-host 127.0.0.1 --remote-port 8000 \
  --video-decode va --prompt "pick sandbag" \
  --control-frequency 12 --open-loop-horizon 8 &
P=$!
sleep 22
kill -INT $P 2>/dev/null
wait $P 2>/dev/null
sleep 1
echo "=== 推理已停，进入保持 ==="
python /app/hold_now.py
'
```

这样 **22 秒一到就自动停推理并锁住姿态**，不用盯着抢时间。

---

## 三者的取舍

| 办法 | 优点 | 缺点 |
|---|---|---|
| A 直接停 | 一条命令 | 夹持力不确定 |
| **B 保持脚本** | **稳定、可控、可松开** | 多一步 |
| C 定时+保持 | 不用盯时机 | 时间要预估准 |

**建议演示用 C**：给 20~25 秒让它抓起来，时间一到自动锁住，然后从容展示。

---

## 演示时的完整节奏

```
1. 摆好 v3 起点（pose_v3.sh）
2. 沙包放在训练时那个位置
3. 跑办法 C（22 秒后自动停 + 保持）
4. 展示：夹着的沙包、稳定的姿态
5. 需要交付时：GRIP_TRIGGER=0.0 再跑一次 hold_now.py 松开
```
