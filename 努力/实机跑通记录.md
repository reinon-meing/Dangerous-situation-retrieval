## 二、根因（一句话）

> **训练端 openpi 用"绝对关节角"（`use_delta_joint_actions=False`），B70 推理端代码版本较新、默认"增量"（`True`），导致推理时把当前关节角加了两次 → 下发值 ≈ 当前值 × 2 → 全部顶到限位。**

### 证据链

| 检查 | 结果 |
|---|---|
| A100：`get_config("pi05_teleavatar_v2").data.use_delta_joint_actions` | **False** |
| B70 server 日志里的 `LeRobotTeleavatarV2DataConfig` | **True** |
| checkpoint 里 `norm_stats.json` 的 actions 统计 | 绝对角度（q01 `[0.029, 1.036, -1.095]`，与 state 统计几乎一致）→ **本来就是对的** |
| 实机下发值 vs 当前值 | 精确等于 `当前值 × 2 + 小增量`（l_j2 2.746≈2×1.361、r_j7 -1.300≈2×(-0.652)） |
| 离线对照实验（强制 delta=True） | 预测值 vs `2×当前值` 的 MAE = **0.057 弧度**，与实机完全吻合 |

### 修复（3 处，改一个文件）

`/root/USB/deploy/server/openpi/src/openpi/policies/teleavatar_v2_policy.py`

| 位置 | 改动 |
|---|---|
| `TeleavatarInputs.__call__` | `if self.use_delta_joint_actions:` → `if False:` |
| `TeleavatarOutputs.__call__` | 同上 |
| `delta_action_anchor()` | `if not self.use_delta_joint_actions:` → `if True:`（恒返回 None） |

脚本：[`脚本/fix_b70_absolute.py`](脚本/fix_b70_absolute.py)。**改完必须重启 server 才生效**（Python 进程启动时已加载代码）。

## 四、关键参数速查

### 模型与数据布局

```
状态 observation.state:  [左臂 0-6][左夹爪 7][右臂 8-14][右夹爪 15][...]
                         策略只取 [0:7] 和 [8:15]  ← 千万别用 [:14]！
动作 action 16 维:        [左臂 7][左夹爪 effort][右臂 7][右夹爪 effort]
换夹爪:                   effort → trigger，(trigger<0.1 张 / >0.1 合)
```

### 夹爪接口

| 项 | 值 |
|---|---|
| 话题 | `/api/left_gripper/cmd`、`/api/right_gripper/cmd` |
| 类型 | `std_msgs/msg/Float32` |
| 值 | **trigger ∈ [0,1]**：0=全开、0.10=不用力、1.0=全闭（-1.6 Nm） |

### 升降接口

| 项 | 值 |
|---|---|
| 话题 | `/api/servo/cmd` |
| 类型 | `std_msgs/msg/Float32MultiArray` |
| 数据 | **`[归一化速度, 使能]`**，速度 `[-1,1]`（正=上升、负=下降），使能 >0.5 |
| 停止 | `[0.0, 1.0]`（保持使能）→ `[0.0, 0.0]`（失能） |
| 特点 | 不需 FSM 心跳；停发超 3 秒自动减速失能；≥10 Hz 发布 |

### 跑模型的速度控制

| 参数 | 默认 | 说明 |
|---|---|---|
| `--control-frequency` | 45.0 | 动作执行频率，调到 12 ≈ 1/4 速 |
| `--open-loop-horizon` | 16 | 执行几步后重新推理，调 8 更跟手 |
